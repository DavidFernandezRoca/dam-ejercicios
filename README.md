# Ejercicios de Programación — 1º DAM

Ejercicios en **Java** que voy haciendo en el módulo de Programación de 1º de Desarrollo de Aplicaciones Multiplataforma.

Cada archivo lleva el enunciado del ejercicio como comentario al principio.

## Temas

| Carpeta | Tema | Ejercicios |
|---|---|---|
| [01-primeras-instrucciones](01-primeras-instrucciones) | Mostrar por pantalla, variables y tipos, leer datos del teclado | 01 a 05 |
| [02-expresiones-y-calculos](02-expresiones-y-calculos) | Operaciones aritméticas, constantes, áreas y conversiones | 06 a 14 |
| [03-programas-con-expresiones](03-programas-con-expresiones) | Programas completos con cálculos: IVA, temperaturas, tiempo, cadenas | 15 a 20 |
| [04-tomar-decisiones](04-tomar-decisiones) | Condicionales `if` / `else` | 21 a 30 |
| [05-expresiones-simples](05-expresiones-simples) | Expresiones lógicas y relacionales | 31 a 42 |
| [06-ejercicios-de-clase](06-ejercicios-de-clase) | Bucles, `switch` y funciones: cajero automático, sistema de seguridad, números primos, perfectos y amigos… | — |

Iré añadiendo más temas según avance el curso.

## Cómo ejecutar un ejercicio

```
javac Ejercicio01.java
java Ejercicio01
```
